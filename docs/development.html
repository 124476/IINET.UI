Сборка и разработка

Инструкция для локальной работы с репозиторием IINET.UI.

Требования

  • .NET SDK, соответствующий версии, закреплённой в репозитории (если добавлен global.json).
  • NuGet.org или другой настроенный источник пакетов.
  • Linux, Windows или macOS для соответствующей desktop-платформы Avalonia.

Восстановление и сборка

dotnet restore
dotnet build -m:1

Запуск демонстрационного приложения

dotnet run --project samples/IINET.UI.Demo

Управление версиями пакетов

Версии NuGet централизованы в Directory.Packages.props. При обновлении Avalonia проверяйте согласованность основных пакетов: Avalonia, Avalonia.Desktop и используемой темы. После изменения версии выполняйте чистую сборку и запускайте Demo.

Проверка темы компонента

Если календарь отображается без шаблона, проверьте включение Themes/**/*.axaml как AvaloniaResource в проекте компонента и наличие ResourceInclude в ресурсах приложения. Документация Avalonia отдельно описывает библиотечные темы для templated controls.

Полезные команды

dotnet --list-sdks
dotnet --list-runtimes
dotnet sln list
dotnet list package
dotnet clean
dotnet build -m:1

Перед pull request

  • Убедитесь, что проект собирается.
  • Проверьте Demo вручную.
  • Обновите документацию, если изменился публичный API.
  • Не добавляйте папки bin/ и obj/ в Git.
  • Не заявляйте совместимость с версиями Avalonia, на которых не проводилась проверка.
