Запланировано

Быстрый старт в текущем репозитории

Пока пакеты не опубликованы, подключайте проект календаря напрямую:

dotnet add YourApp.csproj reference path/to/IINET.UI.Calendar.csproj

В уже существующем репозитории Demo:

dotnet add samples/IINET.UI.Demo reference src/IINET.UI.Calendar/IINET.UI.Calendar.csproj

После подключения нужно включить ресурс темы avares://IINET.UI.Calendar/Themes/Generic.axaml в App.axaml. Полная инструкция приведена в разделе Установка и подключение.

Установка всей библиотеки одной командой — цель проекта

dotnet add package IINET.UI

Для этого будет опубликован агрегирующий пакет IINET.UI, который зависит от отдельных пакетов компонентов. Например, IINET.UI.Calendar подтянет IINET.UI.Core как транзитивную зависимость. Сейчас это план публикации, а не доступная команда из nuget.org.
