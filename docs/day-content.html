Содержимое дней

Каждая запись CalendarDayContent связывает календарную дату с дополнительным содержимым. Для визуальных элементов рекомендуется использовать фабрику, возвращающую новый экземпляр контрола.

Не переиспользуйте один экземпляр Control в разных ячейках.

У Avalonia Visual может быть только один visual parent. При перестроении календаря ранее размещённый экземпляр нельзя прикрепить повторно. Поэтому фабрика должна возвращать новый объект на каждый вызов.

TextBlock

CalendarDayContent.FromControl(
  new DateTime(2026, 11, 4),
  () => new TextBlock { Text = "📝 Заметка" });

Button

CalendarDayContent.FromControl(
  new DateTime(2026, 11, 12),
  () => new Button { Content = "Открыть" });

StackPanel с несколькими элементами

CalendarDayContent.FromControl(
  new DateTime(2026, 11, 14),
  () => new StackPanel
  {
    Children =
    {
      new TextBlock { Text = "📚" },
      new Button { Content = "Учёба" }
    }
  });

Несколько элементов в одной дате

CalendarMarks.Add(CalendarDayContent.FromControl(
  new DateTime(2026, 11, 26),
  () => new TextBlock { Text = "🎉" }));

CalendarMarks.Add(CalendarDayContent.FromControl(
  new DateTime(2026, 11, 26),
  () => new TextBlock { Text = "Праздник" }));

Коллекция и Binding

public ObservableCollection<CalendarDayContent> CalendarMarks { get; } = new();

public MainWindow()
{
    InitializeComponent();
    DataContext = this;
}
<calendar:Calendar DayContents="{Binding CalendarMarks}" />

При использовании ObservableCollection календарь получает уведомление об изменении коллекции и обновляет ячейки. Для интерактивных вложенных элементов (например, кнопок и флажков) настройте обработку pointer-событий так, чтобы их нажатия не запускали выбор родительской даты.

Какие элементы можно размещать

Подойдёт любой контрол Avalonia, например TextBlock, Button, CheckBox, StackPanel, Grid, Border, фигуры или собственный компонент.
