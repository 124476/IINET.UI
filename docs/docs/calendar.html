Calendar

IINET.UI.Calendar — первый компонент IINET.UI. Он отображает месячную сетку, позволяет выбирать дату, перемещаться между месяцами и выводить произвольные Avalonia-контролы в ячейках.

Основные свойства

СвойствоНазначение
SelectedDateВыбранная дата. Поддерживает двустороннюю привязку.
DisplayDateДата, определяющая отображаемый месяц.
FirstDayOfWeekПервый день недели, например Monday или Sunday.
WeekdayLabelsСемь подписей через запятую. Порядок значений — понедельник–воскресенье.
MonthNamesДвенадцать названий через символ |, январь–декабрь.
DayContentsКоллекция дополнительных элементов с привязкой к датам.
DateSelectedСобытие, возникающее при выборе даты; передаёт DateTime.

Базовое использование

<calendar:Calendar
  SelectedDate="{Binding SelectedDate, Mode=TwoWay}"
  FirstDayOfWeek="Monday"
  WeekdayLabels="Пн,Вт,Ср,Чт,Пт,Сб,Вс"
  DayContents="{Binding CalendarMarks}" />

Подписка на выбор даты

calendar.DateSelected += date =>
{
    Console.WriteLine($"Выбрана дата: {date:dd.MM.yyyy}");
};

Размеры

Для изменения минимальных размеров используйте стандартные свойства Avalonia MinWidth и MinHeight. Для заполнения контейнера задайте HorizontalAlignment="Stretch" и VerticalAlignment="Stretch"; родительский контейнер должен предоставлять доступное пространство.

Содержимое ячеек

Для добавления контролов используйте CalendarDayContent.FromControl(date, factory). Примеры: Содержимое дней.
