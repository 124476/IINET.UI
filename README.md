# IINET.UI

**IINET.UI** — библиотека пользовательских интерфейсов для [Avalonia UI](https://avaloniaui.net/), содержащая набор переиспользуемых компонентов для разработки приложений на .NET.

Проект развивается как коллекция независимых UI-компонентов с возможностью дальнейшего расширения.

## Документация

Полная документация библиотеки доступна на GitHub Pages:

**[124476.github.io/IINET.UI](https://124476.github.io/IINET.UI/)**

В документации представлены:
- установка и подключение библиотеки;
- использование компонентов;
- настройка внешнего вида;
- примеры кода;
- сборка и разработка проекта.

## Компоненты

На данный момент библиотека включает:

### Calendar

Календарный компонент для Avalonia UI.

Основные возможности:
- отображение календаря по месяцам;
- настройка первого дня недели;
- выбор даты;
- настройка цветов и оформления;
- изменение внешнего вида заголовка и навигации;
- добавление произвольных элементов к отдельным датам;
- настройка шаблонов содержимого дней.

Подробнее: [Документация Calendar](https://124476.github.io/IINET.UI/calendar.html).

## Разработка

Для сборки проекта потребуется установленный .NET SDK.

Клонирование репозитория:

```bash
git clone https://github.com/124476/IINET.UI.git
cd IINET.UI
```

Сборка решения:

```bash
dotnet build
```

Запуск демонстрационного приложения:

```bash
dotnet run --project samples/IINET.UI.Demo
```
